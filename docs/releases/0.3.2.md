# Hopper 0.3.2

Administrator-controlled network settings, without firewall confirmation gates.

- Remove the RCON firewall confirmation requirement from system start, restart, and
  updates, including scheduled maintenance. Remove `--rcon-firewall-confirmed` and
  its stored confirmation; existing instance records continue to load.
- Add `hopper ports NAME --game PORT --rcon PORT` to set game and RCON ports, and
  `hopper listen NAME ADDRESS` to set Minecraft's `server-ip`. Addresses accept
  IPv4, IPv6, `localhost`, or `*` for all interfaces. Omit values to inspect settings.
- Changes preserve other properties and the RCON password, update the instance record,
  and apply on the next start or restart. Both verbs support system scope and JSON output.
- Preserve explicit ports during onboarding without probing or renumbering them.
  Allocate ports only when unspecified, and avoid probing coordinator-assigned ports
  again in installation workers. Dry runs no longer allocate ports.
- Local RCON connections and player counts follow the configured listen address,
  including IPv6 and wildcard listeners. Pending endpoint changes retain the running
  server's control endpoint until the next service start.

The release includes a statically linked Linux x86-64 binary and SHA256SUMS.
