# Hopper 0.3.4

Managed updates now stage a clean new pack and review only local customizations.

- Audit tracked files against the installed version's pristine baseline before
  staging. Unchanged files update or disappear with the new pack without prompting,
  including files adopted during onboarding.
- Automatically merge independent text edits using the installed baseline, local
  content and incoming defaults. Overlapping edits, binary changes and unavailable
  baseline content require review. Customized files removed upstream offer an
  explicit keep-or-remove choice; admin-deleted files remain absent.
- Build the new installation in an isolated clean room. After shutdown and a verified
  backup, carry worlds, server.properties, operator settings and custom additions
  into it before swapping installations and validating startup.
- Preserve the new upstream baseline separately from retained or merged custom
  content so subsequent updates review only admin changes.
- Exclude temporary update work from rolling backups, reserve additional space for
  the stopped-world copy, and recover interrupted directory swaps from the verified
  snapshot.

Automatic text merging is line-based and does not validate configuration semantics
or replace pack-specific migration instructions. Missing baseline bytes and bounded
merge limits fall back to review. Existing backup and revert commands remain available.

The release includes a statically linked Linux x86-64 binary and SHA256SUMS.
