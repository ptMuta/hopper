# Hopper 0.3.3

A new patch release of the code shipped in 0.3.2, with updated version metadata.
There are no additional behavior changes.

Includes administrator-controlled game/RCON ports and listen addresses, removal of
the RCON firewall confirmation gate, preserved explicit ports, and active RCON
endpoints retained until pending network changes take effect at service start.
Also includes automatic sudo elevation for system commands and the CurseForge
credential fixes from 0.3.1.

The release includes a statically linked Linux x86-64 binary and SHA256SUMS.
